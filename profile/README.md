## What you'll find here

- **Open source** — reusable software and practical utilities.
- **Developer tools** — focused tools that make everyday workflows easier.
- **Experiments** — prototypes and research projects that explore new ideas.
- **Learning in public** — clear documentation, honest progress, and lessons from building.

## Featured project

- [**Descent Lab — Rocket Landing AI**](https://github.com/playlikemen/descent-lab-rocket-landing-ai) — a local-first reinforcement-learning lab for a simplified 2D rocket-landing task, with an interactive browser simulator and evaluation tools.

## Our principles

- Build useful things, not just demos.
- Keep software approachable and documentation clear.
- Prefer simple solutions that are easy to understand and improve.
- Share work openly and welcome constructive contributions.

## Contribute

Explore the repositories, open an issue when you spot a problem or have an idea, and submit a pull request when you have an improvement. Please read each project's README and license before using or contributing.
